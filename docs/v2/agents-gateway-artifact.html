A file becomes

Agents Gateway is a declarative execution layer for running a Codex agent inside a bounded sandbox with only the skills, MCP tools, model route, filesystem, and network access described by its bundle.

What happens when you run a bundle?

The CLI is a thin convenience layer. It compiles the friendly file into the same immutable resources used by the lower-level API, then follows one durable run.

01 / AUTHOR

AgentBundle

Prompt, model, skills, MCP grants, sandbox limits, verification, artifact preferences.

02 / COMPILE

Immutable plan

Strict decode, path containment, digest validation, deterministic resource revisions.

03 / APPLY

Control plane

Agent, SkillSet, ToolSet, ModelRoute, SandboxProfile, and credential references.

04 / EXECUTE

Sandbox + brokers

Codex runs in rootless Podman. Model, MCP, Skills, and artifacts cross loopback brokers.

05 / PRESENT

Run workspace

Redacted activity, terminal status, primary artifact, supporting outputs, cleanup.

How modular is it?

Each concern is a replaceable boundary. The personal profile is intentionally small, but the interfaces leave room for stronger runners and providers later.

Authoring

AgentBundle is the human-facing contract. It can reference inline or reusable model, sandbox, skill, and tool definitions without embedding secrets.

v2/pkg/spec

Control plane

Immutable resources + revisions make a run reproducible and auditable. The CLI can be replaced by an API, UI, or CI job.

v2/pkg/httpapi · store

Harness

Codex adapter is behind a runtime protocol. A future Claude, OpenCode, or another harness can implement the same boundary.

v2/pkg/codexadapter

Model routing

Responses broker exposes a loopback-only endpoint to the sandbox and resolves OpenAI/OpenRouter credentials outside it.

v2/pkg/brokerfactory

Tool routing

MCP broker + policy ledger exposes only selected servers/tools and records authorization and outcome events.

v2/pkg/toolbroker

Artifact system

Catalog + content API validates descriptors, hashes bytes, stores immutable versions, and renders safe previews in the console.

artifactcatalog · console

Runner boundary

Host-side runner owns sandbox lifecycle over a Unix socket or authenticated transport. The control plane never receives a container-runtime socket.

cmd/agw-runner · runnerdispatch

Persistence

PostgreSQL + RLS stores tenant-scoped resources, revisions, runs, events, audit records, and artifact catalog metadata.

pkg/store · migrations

Identity + console

Owner auth and React console provide scoped API access, SSE activity, artifact previews, and run troubleshooting without putting tokens in artifacts.

identity · authz · web

The mental model

A bundle is closer to infrastructure-as-code than to a chat prompt. The file describes an execution contract; the run is a concrete instance of that contract.

apiVersion: agents.astatide.com/v1alpha1 kind: AgentBundle metadata: name: repository-reviewer spec: prompt: prompts/review.md model: OpenAI Responses route skills: pinned revisions mcp: explicit grants only sandbox: rootless + brokered artifacts: required
What is deterministic?

The selected tools, skill digests, runtime image, limits, prompt inputs, resource digests, event history, and artifact contract.

The model’s wording and tool-use quality are not deterministic. That is why the system validates outputs, keeps an auditable event trail, and fails closed on malformed artifacts.

Security boundaries

Secrets and privileged integrations stop at the broker boundary. The sandbox receives capabilities, not raw credentials.

◈

Sandbox

Rootless Podman, ephemeral workspace, read-only root, bounded CPU/memory/disk/PIDs, no direct internet, no-new-privileges.

↗

Broker

OpenAI/OpenRouter, MCP, Skills Gateway, and artifact access are loopback endpoints. Host-side services resolve credentials.

▣

Output

Events redact sensitive material. Artifact descriptors reject traversal and unknown fields; content is hashed and previewed defensively.

What exists today vs. what is later?

Ready now

Personal declarative bundles · Codex sandbox runtime · OpenAI/OpenRouter model routes · Skills Gateway references · scoped MCP tools · artifacts · activity logs · cancellation · cleanup · console run/artifact views.

Deliberately deferred

Public multi-tenant hostile-code isolation · Kubernetes · distributed workflow orchestration · collaboration/sharing · artifact remix APIs · cursor pagination · subscription/OAuth entitlement brokering.
